# OASIS Landing Page

Framer로 만들었던 `https://oasis24.framer.ai/` 랜딩 페이지를 도메인 이전/FE 공유용 정적 페이지로 재구성한 작업 폴더입니다.

## 파일 구조

- `index.html`: 페이지 마크업
- `styles.css`: 레이아웃, 컬러 토큰, 반응형 스타일
- `script.js`: 스크롤 등장 모션
- `assets/`: Framer 원본에서 내려받은 주요 이미지
- `framer-source.html`: 참고용 원본 HTML 스냅샷

## 확인 방법

브라우저에서 `index.html`을 열면 바로 확인할 수 있습니다.
